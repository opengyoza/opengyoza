# Contributing

## Scope
This repository is in early bootstrap. Please coordinate significant changes with maintainers.

## Workflow
- Prefer small, focused changes.
- Update `CHANGES_FROM_UPSTREAM.md` when behavior changes.
- Keep planned structure aligned with `opengyoza_plan.md`.

## Testing
- All tests must be green before declaring the fork “working.”
- Use TDD where possible and record failures with logs.
