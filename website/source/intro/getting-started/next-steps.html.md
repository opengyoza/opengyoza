# Next Steps

That concludes the getting started guide for OpenGyoza. Hopefully you're able to
see that while OpenGyoza is simple to use, it has a powerful set of features.
We've covered the basics for all of these features in this guide.

OpenGyoza is designed to be friendly to both the DevOps community and
application developers, making it perfect for modern, elastic infrastructures.

As a next step, the following resources are available:

* [Documentation](/docs/index.html) - The documentation is an in-depth reference
  guide to all the features of OpenGyoza, including technical details about the
  internals of how OpenGyoza operates.

* [Guides](/docs/guides/index.html) - This section provides various getting
  started guides with OpenGyoza, including how to bootstrap a new datacenter.

* [Examples](https://github.com/opengyoza/opengyoza/tree/main/demo) -
  The work-in-progress examples folder within the GitHub
  repository for OpenGyoza contains functional examples of various use cases
  of OpenGyoza to help you get started with exactly what you need.
