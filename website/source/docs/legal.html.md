# Legal

This page summarizes the licensing, attribution, and trademark posture for
OpenGyoza. It is not a substitute for the full license texts or repository
notices.

## License

OpenGyoza is distributed under the Mozilla Public License 2.0 (MPL-2.0).
See the repository `LICENSE` file for the full license text. Where applicable,
third‑party components and notices are documented in `NOTICE.md` and any
project‑specific legal notes in `LEGAL.md`.

## Attribution

OpenGyoza is a community‑maintained fork of HashiCorp Consul 1.6.4. The fork
preserves protocol and operational compatibility while removing enterprise‑only
code paths and rebranding the CLI to `gyoza` with a `consul` compatibility shim.
