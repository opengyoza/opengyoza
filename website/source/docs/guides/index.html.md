# OpenGyoza Guides

~> The upstream Consul guides live on the [HashiCorp Learn platform](https://learn.hashicorp.com/consul?utm_source=consul.io&utm_medium=docs&utm_content=guide-index). They are still applicable, but you should substitute `gyoza` for `consul` in CLI examples (or rely on the compatibility shim).

## OpenGyoza-specific guides

- [Migrate from Consul to OpenGyoza](/docs/guides/gyoza-migration.html)

[Guides](https://learn.hashicorp.com/consul?utm_source=consul.io&utm_medium=docs&utm_content=guide-index) are step by step command-line
walkthroughs that demonstrate how to perform common operations using OpenGyoza, and
complement the feature-focused OpenGyoza documentation.

Guide content begins with getting-started tracks to help new users learn the
basics of OpenGyoza, and continues through production-playbook tracks that cover
topics like Day 1 and Day 2 operations, production considerations, and
recommendations for securing your OpenGyoza cluster.

You can work through the guides sequentially using the tracks, or just refer to
the material that is most relevant to you.

Tracks include:

- Getting Started
- Getting Started with Kubernetes
- Setup a Secure Development Environment
- Day 1: Deploying Your First Datacenter
- Day 1: Security and Network Operations
- Day 1: Kubernetes Production Deployment
- Maintenance and Monitoring Operations
- Service Discovery and OpenGyoza DNS
- Service Segmentation and OpenGyoza Connect
- Service Configuration and OpenGyoza KV
- Cloud and Load Balancer Integrations
