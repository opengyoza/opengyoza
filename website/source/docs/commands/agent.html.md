# OpenGyoza Agent

The `gyoza agent` command is the heart of OpenGyoza: it runs the agent that
performs the important task of maintaining membership information,
running checks, announcing services, handling queries, etc.

Due to the power and flexibility of this command, the OpenGyoza agent
is documented in its own section. See the [OpenGyoza Agent](/docs/agent/basics.html)
section for more information on how to use this command and the
options it has.
