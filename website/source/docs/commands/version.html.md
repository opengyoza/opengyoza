# OpenGyoza Version

Command: `gyoza version`

The `version` command prints the version of OpenGyoza and the protocol versions it understands for speaking to other agents.

```text
$ gyoza version
OpenGyoza v0.7.4
Protocol 2 spoken by default, understands 2 to 3 (agent will automatically use protocol >2 when speaking to compatible agents)
```
